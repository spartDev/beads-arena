# Glossary

The words this project uses, and the ones it avoids. Updated inline while grilling: when a term is
settled, it lands here before the conversation moves on.

| Term | Definition | Avoid |
|---|---|---|
| Ticket | A bead an agent or a human can finish in one PR | issue, story (unless the type is story) |
| Season | One arena-season molecule: an epic from hypothesis to validated value | project, initiative |
| Round | One arena-round wisp: a ticket driven to a merged PR | run, job |
| Bout | One arena-bout wisp: N candidates contesting a ticket's shape | spike (a spike is a ticket type) |
| Pit | Everything waiting on a human decision | backlog |
